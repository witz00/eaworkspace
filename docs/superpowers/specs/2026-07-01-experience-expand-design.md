# Раскрывающийся список в разделе «Опыт»

## Цель
Добавить возможность раскрыть каждый пункт в разделе «Опыт» (`src/sections/experience.js`), чтобы показать текстовое описание обязанностей и достижений на позиции.

## Layout строки
`.exp-row` сохраняет текущую структуру (лого + инфо слева), справа добавляется кнопка-тогглер, период остаётся между инфо и кнопкой:

```
[лого] [компания/роль]  ...  [период]  [toggle-btn]
```

Ниже строки — раскрываемый блок с описанием (только когда открыт).

## Кнопка-тогглер
Стилизуется как `.theme-toggle`:
- 44×44px, `border-radius: 12px`
- `background: var(--btn-bg)`, `border: 1px solid var(--border)`
- Иконка 20×20 по центру, `filter: var(--icon-filter)`
- `transition: background 0.5s` на hover (как у theme-toggle), `hover { background: var(--border) }`

Иконка: `assets/arrow-left.svg` (стрелка влево, stroke `#636363`).
- По умолчанию повёрнута на `-90deg` (указывает вниз → «раскрыть»)
- При открытом состоянии — `rotate(90deg)` от базы (итого стрелка вверх → «свернуть»)
- `transition: transform 0.3s`

## Раскрываемый контент
При клике на кнопку (или на весь `.exp-row` — открывать по клику на кнопку, чтобы не конфликтовать с будущими кликами по логотипу/тексту) добавляется/убирается класс `.open` на обёртке пункта (`.exp-item`, новый враппер вокруг `.exp-row` + панель).

Панель содержит:
- **Обязанности** — абзац текста
- **Достижения** — маркированный список (`<ul><li>`)

Анимация: `max-height` + `opacity` transition (~0.3s), т.к. `display:none/block` не анимируется. Высота блока не фиксирована (списки разной длины), поэтому используем большое max-height (например `1000px`) при открытии, либо через `grid-template-rows: 0fr → 1fr` (более надёжный современный способ, без магических чисел) — **выбираем grid-подход**.

## Поведение
- Каждый пункт раскрывается/сворачивается **независимо** (не аккордеон).
- Клик по кнопке тогглит `.open` только на своём пункте.
- Клавиатурная доступность: кнопка — обычная `<button>`, доступна по Tab/Enter/Space по умолчанию.

## Мобильная адаптация
Существующие мобильные стили (`.exp-row { flex-direction: column }` в media query) сохраняются; кнопка-тогглер остаётся справа/сверху в компактном виде — уточнить визуально при реализации, но функционально не отличается от десктопа.

## Тестирование
Ручная проверка в браузере (dev server): раскрытие/сворачивание каждого пункта независимо, сохранение состояния других пунктов, поворот иконки, адаптив на мобильной ширине.
