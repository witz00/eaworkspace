# Страница кейса внутри «Проекты» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Clicking a case card in the Projects section shows a case-detail view (breadcrumb + "В разработке" placeholder) inside the same right-side container, without touching the left nav or `.card-right` structure; clicking either breadcrumb segment returns to the grid.

**Architecture:** `renderProjects(container)` in `src/sections/projects.js` gains two internal render functions — `renderGrid()` and `renderCase(i)` — both writing to the same `container.innerHTML` and re-attaching their own click listeners after each render. No changes to `main.js` or nav.

**Tech Stack:** Vanilla JS (ES modules), vanilla CSS. No test framework in this repo — verification is manual via `npm run dev` + browser check at the end of each task.

## Global Constraints

- No test framework exists — verify manually in the browser per task, plus `npm run build` for syntax/bundling errors.
- Only `src/sections/projects.js` and `src/style.css` are touched — no changes to `main.js`, `index.html`, or any other section file.
- Case view always shows the placeholder text "В разработке" in the body (matches spec — cases have no real content yet).
- Breadcrumb text for the second segment comes from `cases[i].company` (e.g. "Кейс 1", "Кейс 2").
- Both breadcrumb segments are clickable and both return to the grid view (per spec — neither is a dead end, neither navigates anywhere else).
- Grid cards (`.proj-grid-card`) stay visually empty `div`s — no text/image added to them.
- Entering the Projects section always starts at grid view (no persistence of a previously open case).
- Breadcrumb visual style: reuses `.section-label`-like sizing (24px desktop, 15px mobile matching the existing `.section-label` mobile override at `src/style.css:928`), separator `/` colored `var(--dim)`, links colored `var(--dim)` except the last segment which is `var(--white)`, hover also `var(--white)`.

- Internal DOM contract Task 2 (CSS) depends on: grid view unchanged (`.content-area.proj-grid-area` > `.section-label` + `.proj-grid` > `.proj-grid-card[data-index]`); case view is `.content-area.proj-grid-area` > `.proj-crumb` (containing two `.proj-crumb-link` buttons and one `.proj-crumb-sep` span) > `.proj-case-body` containing a `<p>` with the placeholder text.

- [ ] **Step 1: Replace `renderProjects` with grid/case view switching**

Replace the full contents of `src/sections/projects.js` (currently lines 1-25) with:

```javascript
const cases = [
  {
    title: 'В разработке',
    company: 'Кейс 1',
    description: '',
    wip: true,
  },
  {
    title: 'В разработке',
    company: 'Кейс 2',
    description: '',
    wip: true,
  },
]

export function renderProjects(container) {
  function renderGrid() {
    container.innerHTML = `
      <div class="content-area proj-grid-area">
        <span class="section-label">Проекты</span>
        <div class="proj-grid">
          ${cases.map((_, i) => `<div class="proj-grid-card" data-index="${i}"></div>`).join('')}
        </div>
      </div>
    `

    container.querySelectorAll('.proj-grid-card').forEach(card => {
      card.addEventListener('click', () => {
        renderCase(+card.dataset.index)
      })
    })
  }

  function renderCase(i) {
    const c = cases[i]
    container.innerHTML = `
      <div class="content-area proj-grid-area">
        <div class="proj-crumb">
          <button class="proj-crumb-link" type="button">Проекты</button>
          <span class="proj-crumb-sep">/</span>
          <button class="proj-crumb-link" type="button">${c.company}</button>
        </div>
        <div class="proj-case-body">
          <p>${c.title}</p>
        </div>
      </div>
    `

    container.querySelectorAll('.proj-crumb-link').forEach(link => {
      link.addEventListener('click', renderGrid)
    })
  }

  renderGrid()
}
```
